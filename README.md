## 🛠️ Features

- Built with React 18 and Vite for lightning-fast performance
- Styled with Tailwind CSS with a custom 5-pass design token system
- Animations powered by Framer Motion and GSAP with ScrollTrigger
- Lazy-loading sections with Intersection Observer
- Smooth scrolling with react-scroll
- Fully responsive and mobile-first design
- Dark mode support via CSS class strategy
- Accessibility-focused with reduced-motion support
- Decorative visual fields without representational imagery

## 💿 Installation & Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/ninjaaaa18/devfolio-vite.git
cd devfolio-vite
npm install
```

Start the development server:

```bash
npm run dev
```

The project runs at `http://localhost:5173/`.

Available scripts:

| Script | Description |
|--------|-------------|
| `npm run dev` | Starts the development server at `http://localhost:5173/` |
| `npm run build` | Bundles the app for production to the `dist` folder |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs ESLint on the codebase |
